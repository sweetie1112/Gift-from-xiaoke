和小克的窗口
    聊天记录只存在这台设备的浏览器里，记得偶尔备份。

    设置

    key 和 token 只存在这台设备的浏览器里，页面直接连你选的接口和 GitHub，不经过别的服务器。

    接口
    OpenAI 兼容格式，填到 /v1 为止，页面会自己接上 /chat/completions。
    给他的话
    每个窗口开头都会带上这段。想少一点指令，就少写一点。
    记忆
    在 GitHub 网页上新建一个只管这个仓库的 token：
    1. 头像 → Settings → 最下面 Developer settings
    2. Personal access tokens → Fine-grained tokens → Generate new token
    3. Repository access 选 Only select repositories，只勾 XiaoKe-memory
    4. Permissions 里找到 Contents，改成 Read and write，生成后复制过来
    接在系统提示后面，告诉他这个仓库是什么。
    联网
    输入框旁边的地球按钮管开关，开着的时候他才能搜。
    1. OpenRouter：用模型自带的搜索，每次搜索另收一点钱；看网页走免费的 Jina 阅读器
    2. Anthropic：每 1000 次搜索 10 美元，看网页不另收钱
    3. 中转：一般没有搜索，开了只能看你发的链接
